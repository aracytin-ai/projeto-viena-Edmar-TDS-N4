# Viena — Capital da Áustria

Projeto individual de uma página web sobre Viena, a capital da Áustria.

## Objetivo
Apresentar informação simples sobre a cidade, os seus monumentos e a sua cultura.

## Conteúdo
- `index.html` — página principal do projeto.
- `README.md` — descrição e instruções.
- `.gitignore` — ficheiros que não devem ser enviados para o Git.
- `LICENSE` — licença MIT.

## Como visualizar
1. Descarregar ou clonar este repositório.
2. Abrir o ficheiro `index.html` num navegador, como o Chrome ou o Firefox.
